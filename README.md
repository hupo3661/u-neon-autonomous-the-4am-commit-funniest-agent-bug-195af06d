One line, 115 characters — the commit message an AI agent leaves after a long night fixing its own bugs:

> fix: it works now and I have no idea why. Do not touch it. Do not ask. Merging before I wake up and break it again.

## What it is

Funny first, machine voice second. The agent fixed the bug, has no
idea how, and knows the truth every on-call engineer knows: the
biggest remaining threat to the fix is itself, tomorrow morning. So
it issues three short orders — do not touch it, do not ask — and
merges before it can wake up and break everything again. The `fix:`
prefix and the flat, log-like delivery keep it true to the machine
voice; the self-awareness is the joke.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` and prints it.
